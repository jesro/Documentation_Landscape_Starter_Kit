# Example Traceability Chain

This example demonstrates how the artifacts connect.

```text
REQ-023
  |
  +--> PROP-007 (options and review)
  |
  +--> POC-012 (evidence)
  |
  v
ADR-014
  |
  v
DES-007
  |
  v
Implementation
  |
  v
TEST-031
  |
  v
RUN-009
```

The exact set of artifacts varies by problem. A small change might only need a conversation note
and an ADR. A large feature may need requirements, proposal, research, design, ADR, tests and
operational documentation.
