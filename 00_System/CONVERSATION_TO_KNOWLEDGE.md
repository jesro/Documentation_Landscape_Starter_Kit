# Conversation -> Knowledge Promotion Rules

## Raw conversation

Use `10_Conversations/`.

## Question / unknown

If uncertainty matters, create a research/spike artifact.

## Evidence

If working feasibility code or comparative measurements are required, use PoC/benchmark artifacts.

## Options

If several credible options need structured review, create an RFC/design proposal.

## Decision

When a durable architectural commitment is made, create an ADR.

## Consequence

Update the relevant architecture/design/runbook and tests.

## Change later

If the architectural commitment changes, create a new ADR rather than rewriting history.

## Important

Most conversations should remain conversations.

Most spikes should remain evidence.

Only load-bearing decisions deserve promotion to durable ADRs.
