# Decision Records

Recommended default: **MADR**.

Use lighter Y-Statements during workshops when speed matters, and expand important decisions into
full ADRs. Use heavyweight IEEE/Tyree-style records only when the audit/traceability requirement
is real.

Keep superseded decisions. Update status and link to the successor.


## MADR customization

The `MADR.md` file is **MADR-based, not a verbatim stock MADR template**. It adds `Validation /
evidence` and `Traceability` sections so decisions can point to research evidence and related
requirements, designs and tests.
