# ADR Template Collection Reference

Joel Parker Henderson's ADR collection is a **collection of templates and examples**, not a
single decision-record methodology.

Use this file as an index when comparing ADR styles.

## Candidate formats

- Nygard
- MADR
- Y-Statement
- RFC-style
- Alexandrian / pattern-form
- Other organization-specific variants

## Selection rule

Choose the simplest format that captures the evidence and governance required by the decision.

## Chosen project default

MADR

## Exceptions

Document why an alternative format is used.
